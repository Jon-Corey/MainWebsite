## What it does

Game Tally is an app for keeping track of the score while playing board games and card games. It's especially helpful for keeping track of health totals in games like Magic: The Gathering or Star Realms.

Game Tally was built from the ground up to be simple and intuitive to use.

## Key Points

- Native app experience on every device (iOS, Android, Windows, macOS, Linux, and Web)
- Free to use with no full-screen ads
